# 🍅 Pomodoro Timer

A simple **Pomodoro Timer desktop application** built with Python and Tkinter.

The application uses the Pomodoro Technique to alternate between focused work sessions and breaks.

## ⏱️ How It Works

The timer follows the Pomodoro Technique:

- 25 minutes of focused work
- 5-minute short break
- After 4 work sessions, a 20-minute long break
- A ✔ is added after every completed work session

The cycle repeats automatically.
